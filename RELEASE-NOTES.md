# Hamster Video 0.2.0 Beta

One Universal installer for **Intel and Apple silicon Macs running macOS 15 or later**.

- Choose Apple compatible H.264/MP4, original source codecs, or HEVC/H.265 MP4.
- Choose an audio language actually offered by the video site, for video or MP3 downloads.
- Cycle Automatic → Light → Dark using the small icon at the top right.
- Removed the subtitles option.
- Retained the hamster icon, preferences, download history, queue and quality controls.

Download **HamsterVideo-0.2.0-beta2-Universal.dmg** below. Open it and drag Hamster Video into Applications. Quit the previous version before replacing it.

This beta is ad-hoc signed and not Apple-notarized. See the README for first-launch instructions. Apple silicon code is cross-compiled and structurally checked; it still needs testing on an Apple silicon Mac. Encoding availability depends on the Mac, and audio languages depend on the source site. See REPORT.md for verification details.

Beta 2 packaging correction: rebuilt the Finder/Dock icon from the cheek-free artwork, changed its resource name and incremented the bundle build number. App functionality is unchanged.
