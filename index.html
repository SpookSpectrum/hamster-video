Installation note for the current beta

The current beta is not Apple-notarized. If macOS blocks the first launch, try opening the app, then go to System Settings → Privacy & Security and use the app-specific Open Anyway option. Audio language options and maximum resolution depend on the original source. Please download only content you are permitted to save.
